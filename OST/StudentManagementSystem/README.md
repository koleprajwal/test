
# Student Management System

A small demonstration Python project for the
Open Source Technology experiment.

## Features

- Displays a student management demo message.
- Uses Python 3.
- Demonstrates Git and GitHub workflow.

## Requirements

- Python 3
- Git

## How to Run

1. Clone or download the repository.
2. Open a terminal in the project directory.
3. Run:

   python main.py
