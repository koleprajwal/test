The important implementation rule is that the 50 Hz interrupt must not perform I2C transactions, filtering, or UART transmission itself. It should set a sample flag. The main loop processes that sample and starts nonblocking UART DMA transmission when the previous transmission has finished.

This prevents slow peripheral operations from blocking the timer interrupt.

Calibration sequence
1. Keep the IMU completely stationary. Allow it to warm up, then collect several hundred samples. Estimate the gyro bias on all three axes.
2. Calibrate the accelerometer. For a single stationary orientation, estimate the bias using the known gravity magnitude and the expected gravity direction. For better bias and scale estimation, collect data in multiple orientations.
3. Apply a low-pass filter. Filter the acceleration magnitude before peak detection so that a sharp impact does not automatically become a step.
4. Use a step state machine. Accept a peak only after the signal crosses a threshold, satisfies the minimum step interval, and has re-armed below a lower threshold.
5. Validate actual walking. Test normal walking, hard foot strikes, stair ascent, stair descent, and standing still. Tune thresholds using the recorded data.
One correction to your assumption: a single stationary calibration cannot eliminate every accelerometer error, and a gyro bias calibration does not eliminate long-term orientation drift. Temperature changes, sensor noise, and mounting movement still matter.

7. What you should test before trusting the trajectory
1. Stationary test: Keep the IMU still during the startup calibration. Confirm the gyro values settle near zero and the step count stays unchanged.
2. Impact test: Tap or strike the foot-mounted sensor. Check whether one impact produces zero or one count, rather than multiple counts.
3. Walking test: Walk 20 measured steps, then compare the STM32 count with the actual number. Repeat at different walking speeds.
4. Stair test: Record ascending and descending separately. Do not assume a change in toe pitch alone proves that a stair was climbed.
5. Trajectory test: Compare the displayed path against a known route. Expect heading drift and imperfect vertical estimates with this six-axis sensor.
The initial detector uses a threshold and a minimum interval between accepted steps. Those settings need tuning against your real data; a hard foot strike can still resemble a valid step.

The included Python script provides an estimated path, not an exact reconstruction of where you walked. The ICM-20608-G has an accelerometer and gyroscope but no magnetometer or absolute-position sensor.
